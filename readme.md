# Based on YOLOv8 deep learning for solar panel defect detection system (YOLO)

## Body

Based on the YOLOv8 deep learning target detection algorithm, this project has developed a highly efficient and precise automatic detection system for solar panel defects. It can identify six common defects, including: black core (black_core), crack (crack), finger-like defect (finger), horizontal dislocation (horizontal_dislocation), short circuit (short_circuit), and thick line (thick_line).
